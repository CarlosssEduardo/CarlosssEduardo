## 📌 Projetos em Destaque e Experiência Prática

### 📦 ERP Logístico e Financeiro
Sistema desenvolvido para otimização de estoque e automação de processos financeiros através de inteligência de dados.
* **Processamento Dinâmico de Dados:** Implementação de leitura inteligente de planilhas Excel sem *schema* fixo, mapeando colunas de custos e fornecedores de forma automatizada e independente da ordem.
* **Inteligência de Estoque:** Desenvolvimento de algoritmo que cruza o inventário físico com o histórico de vendas para classificar a saúde financeira do estoque, emitindo alertas estratégicos sobre capital parado (zero vendas) e itens superestocados.
* **Repositório:** [Acessar no GitHub](https://github.com/CarlosssEduardo/erp-logistico-api)

### 📱 RN Planner (PWA)
Aplicação Web Mobile desenvolvida para digitalizar processos operacionais em um ambiente corporativo real. O sistema gerencia controle de tasks, ofertas, missões e pontuação de remuneração variável para equipes comerciais.
* **Tecnologias:** Java, Spring Boot, React.js, PostgreSQL, Microsoft Azure.

### 🏦 Banco Digital
Sistema bancário desenvolvido em Java com foco em Programação Orientada a Objetos (POO), simulando operações financeiras completas.
* **Features:** Criação de contas, depósitos, saques, transferências e pagamento de boletos.

### ⚙️ API REST de Gestão de Dados
Projeto back-end com foco na estruturação e segurança da informação.
* **Features:** Autenticação, persistência em banco relacional e documentação com Swagger.

### 🔥 Sistema de Detecção de Incêndio com ESP32
Projeto de IoT integrando hardware e software para monitoramento de ambientes.
* **Features:** Sensores DHT11 e MQ2, com acionamento automatizado de relés.
